# Constitutional gap loop — 2026-09-23

## Scope and authority

This iteration implements the user's requested chronological gap audit → neutral follow-up → exact-quote classification → append-only persistence → refreshed event/plane view → subsequent empowerment. The product constitution was read but NOT edited. T0 registration rules and the existing administrator-only local scenario boundary remain unchanged.

## Repairs

1. Added `gap-catalog.ts`, `completeness.ts`, `supplements.ts`, and the `06 补缺访谈` page.
2. Field status distinguishes supported recorded text, a user's explicit unknown, and a system placeholder/pending field. Legacy empty AI-provenance placeholders do not count as complete. An immutable saved record is not advertised as a completed interview.
3. Audit traverses each source-linked plane and each event decision node. Core checks cover the eight interview fields, actual action and the user's subjective best choice. Five contextual fields (goal, constraints, resources, relationships, technology) are tracked separately as evidence coverage. Twenty cognitive dimensions are not converted into twenty compulsory baseline questions.
4. Questions are generated only for pending fields. Already provided answers and explicit unknowns are not asked again. User can defer a question; deferral does not close a gap.
5. `fill-gap` requires confirmation, an existing event and decision node in the same data scope, and exact excerpts from submitted verbatim. Existing-source classification also validates original memory/event linkage. It writes a new memoryStatement; it cannot edit an original event, baseline or transcript.
6. Effective views combine original and supplementary quoted records without rewriting originals or deciding which statement is true. Only pre-decision fields map to similarity inputs. Outcomes/evaluations are never mapped into those features.
7. Direct resource/option/technology records also appear in the linked historical plane's read-only view. T0 question answers remain untouched.
8. New empowerment sessions preserve the supplement IDs used and a completeness snapshot. Replay does not silently import later answers into old results. Scenario-viewpoint filtering blocks later supplements from an earlier simulated query.
9. The output states interview incompleteness explicitly; a lexical candidate is not promoted to a complete decision precedent or a validated cognitive conclusion.

## Boundaries still not claimed as solved

Completeness checking establishes field presence and supported provenance, not whether every quoted passage is semantically adequate or every event boundary is correct. General free-speech interpretation, grouping multiple events into scientifically validated cognitive planes, and semantic decision similarity still require further validation. The matching backend remains conservative lexical comparison. Completing more fields must not be represented as guaranteed scientific validity, a personality assessment, or a success probability.
